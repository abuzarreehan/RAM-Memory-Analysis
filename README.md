# RAM Memory Analysis

## Project Overview
A digital forensics project to investigate malware traces
in RAM memory dumps using Volatility 3.

## Objectives
- Identify suspicious processes
- Investigate hidden or suspicious DLLs
- Analyze network connections
- Generate forensic investigation reports

## Tools
- Python 3.12.4
- Volatility 3
- FTK Imager (optional)
- Visual Studio Cod
